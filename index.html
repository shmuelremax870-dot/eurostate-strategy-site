One example

Mint: an AI workforce for online stores.

Mint is one of the products built on our agent technology. A store owner describes the business in plain words; Mint's specialist agents build the store and then help run it every day, inside the limits the owner sets.

Mint is developed with our technology partner InflueMint, Inc.

Built to be trusted

Built so people stay in control.

In our agent technology, the controls are part of the engine, not a setting on top of it.

  • 01

    Owner approval for money and the live store

    Any action that touches money or the live storefront — publishing, discounts, campaigns — is sealed and waits in an owner-approval queue. No agent can grant itself authority.

  • 02

    Tamper-evident action record

    Every consequential act leaves an authorisation decision and an execution receipt on an append-only journal, sealed into a hash chain that can be verified offline.

  • 03

    Per-business isolation

    Each business is isolated by construction: every call carries an explicit account scope, and agent memory is separated per account and per store.

  • 04

    Bounded AI spend

    AI spend is reserved before each model call, under a hard daily ceiling, so concurrent work cannot exceed it.

The technology

A governed agent engine that remembers, answers to the owner and proves every action.

In Mint, the engine runs a roster of 18 specialised AI agent roles — store building, catalog, pricing, orders, fulfilment, payments, growth and others — on one shared engine, built on Elixir/OTP for parallel, fault-tolerant work.

  1. 01

    Durable by design

    Every agent assignment runs as a durable job on an event-sourced journal in PostgreSQL. After a crash or restart, work is rebuilt from the journal instead of being lost.

  2. 02

    Consequence decides, not the agent

    Actions are classified by what they touch. Money and the live store are sealed for the owner's approval.

  3. 03

    No blind retries

    An effect whose outcome cannot be proven — was the payment captured? — opens a reconciliation case. It is never retried blindly.

  4. 04

    Governed memory

    Memory is versioned and separated per business, behind a gate that refuses ungrounded or secret-bearing memories.

Mint today: running in test stores with a friends-and-family group of store owners, on real store infrastructure and a real supplier catalog.

Data centers

Compute for AI, built in Europe.

Agents need compute. We develop the data-center infrastructure that runs it, in Europe.

Dedicated capacity for AI training, inference and high-performance computing.

EU-hosted and EU-operated, for workloads that need to stay in Europe. We plan to run the open models behind our own agents there too.

  • Sovereign by design

    EU-domiciled, EU-operated, EU-regulated. AI workloads that cannot leave the bloc have a natural home.

  • Built for AI density

    High-density power distribution, liquid-ready cabinets and a fabric suited to training and inference clusters.

  • GPU & CPU capacity

    Accelerators for training and inference, CPU nodes for orchestration and stateful services, shared storage and network.

  • Open, sovereign compute

    Planned: our own GPU inference server running open models for the agents, video ads and vision.
